# Политика безопасности Seednox

> **Слоган:** «Ваши сид-фразы всегда под нашей защитой!»

## Сообщить об уязвимости

Если вы обнаружили уязвимость в безопасности, **не создавайте публичный issue**.

Напишите через [GitHub Security Advisories](https://github.com/novirx-tg/seednox/security/advisories/new) (приватно, рекомендуется).

Мы ответим в течение 48 часов.

## Архитектура безопасности

### Что мы НЕ храним

- Сид-фразы в открытом виде
- Мастер-пароли (ни в БД, ни в логах)
- Ключи шифрования в открытом виде

### Что мы храним (зашифровано)

| Данные | Формат |
|--------|--------|
| Сид-фразы | AES-256-GCM (nonce + ciphertext) |
| Хеш пароля | Argon2id (только для верификации) |
| Соль | 32 байта случайных данных |

### Криптографический стек

```
Мастер-пароль + Соль
        ↓
    Argon2id (KDF)
        ↓
    HKDF-SHA256
        ↓
  AES-256-GCM ключ
        ↓
  Зашифрованная сид-фраза
```

### Привязка к аккаунту

- Каждый пользователь идентифицируется по **Telegram ID**
- Все операции с кошельками проверяют `telegram_id`
- Невозможно получить чужие данные через API бота

### Защита от атак

| Угроза | Мера |
|--------|------|
| Брутфорс пароля | Rate limiting (5 попыток → блокировка 15 мин) |
| Перехват сессии | Таймаут сессии (15 мин неактивности по умолчанию) |
| Утечка через логи | Чувствительные сообщения не логируются |
| Утечка через чат | Сообщения с паролем/сид-фразой удаляются |
| Просмотр экраном | Сид-фраза автоудаляется через 60 сек |
| SQL-инъекции | Параметризованные запросы (aiosqlite) |

## Рекомендации пользователям

1. **Используйте сильный мастер-пароль** (12+ символов, буквы + цифры)
2. **Блокируйте сейф** после каждого использования (`🔒 Заблокировать`)
3. **Не пересылайте** сид-фразы в другие чаты
4. **Self-host** — для максимальной безопасности запускайте бота на своём сервере
5. **Проверяйте код** — проект open-source именно для этого

## Ограничения

- Seednox — **хранилище**, не кошелёк. Мы не подписываем транзакции.
- Telegram не является end-to-end encrypted для ботов. Self-hosting снижает риски.
- Потеря мастер-пароля = **безвозвратная** потеря доступа к сид-фразам.
- Мы не проверяем слова по BIP39 wordlist (только формат). Проверяйте сид-фразу сами.
