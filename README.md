## ✨ Ключевые возможности

- 🗄 **Универсальное хранилище** — храните не только сид-фразы, но и **пароли**, **приватные ключи**, **заметки** и **любые другие данные** — всё в зашифрованном виде.
- 🖥 **Графическое ПК-Приложение (GUI Launcher)** — управление сейфом, генерация бэкапов и запуск бота прямо с рабочего стола Windows.
- 🚀 **Полноценная программа установки (Setup Wizard)** — стандартный установочный `.exe` файл с ярлыками в Пуске и на Рабочем столе, деинсталлятором в Панели управления.
- 🔐 **Шифрование AES-256-GCM & Argon2id KDF** — криптографическая защита всех записей, ключи хранятся исключительно в RAM во время активной сессии с гарантированной зачисткой (Zeroize RAM).
- 🌐 **Обход блокировок Telegram API** — встроенная поддержка HTTP / SOCKS5 прокси и кастомных зеркал Telegram API (для стабильной работы в РФ).
- ☁️ **Автономный 24/7 Хостинг (VPS / Docker)** — экспорт готового `.zip` пакета для развёртывания бота на сервере в 1 клик (рекомендуемый хостинг: **@ohoster** в Telegram).
- 📋 **Быстрый ввод** — правый клик на любом поле → контекстное меню, inline-кнопки вставки токенов/ID, переключатели видимости `👁`.
- 💾 **Портативный формат бэкапов `.snx`** — безопасная миграция и импорт/экспорт между устройствами (новый формат SNX2 с встроенными метаданными KDF).
- 🎭 **Duress-пароль & Plausible Deniability** — ложный сейф при принуждении, скрытая запись событий без компрометации пользователя в аудит-логе.
- 🌱 **Строгая валидация BIP-39** — проверка по официальному словарю из 2048 слов и сверка контрольной суммы (SHA-256 checksum).

## 🚀 Быстрый запуск

### 💻 Установка на Windows x64 (рекомендуется)

1. Перейдите на страницу [GitHub Releases v1.0.3](https://github.com/novirx-tg/seednox/releases/tag/v1.0.3).
2. Скачайте программу установки **`Seednox-Setup-v1.0.3.exe`** (или портативный архив `Seednox-v1.0.3-Windows-x64.zip`).
3. Запустите установщик и следуйте шагам Мастера Установки.
4. Запустите Seednox через ярлык в меню **Пуск** или на **Рабочем столе**.
5. В разделе **«⚙️ Настройки»** вставьте ваш `BOT_TOKEN` и нажмите **«💾 Сохранить»**.

## 📋 Changelog

### v1.0.3 (2026-09-06)
- 🚨 **OpSec & Правдоподобное отрицание**: запись `"unlock"` при входе под принуждением для защиты от анализа audit_log.
- ⏳ **Защита от зависаний интерфейса (UI Freeze)**:
  - Формат бэкапа `SNX2` с сохраненными параметрами KDF.
  - Асинхронный импорт бэкапов в фоновом потоке без блокировки GUI и Telegram-бота.
- 🔑 **Безопасная очистка RAM (Zeroize)**:
  - Пароли хранятся в `bytearray` с занулением памяти `0x00` при блокировке/закрытии окна и вызовом `gc.collect()`.
- 🌱 **Полноценная валидация BIP-39**:
  - Встроенный словарь 2048 слов и проверка SHA-256 контрольной суммы мнемоник.
- ⚙️ **Исправление сборщика Windows**:
  - Устранена ошибка `ModuleNotFoundError: No module named 'pydantic'` при сборке через PyInstaller.

### v1.0.2 (2026-08-01)
- 🚀 **Установочный мастер (Setup Wizard)** — добавлена полноценная программа установки `Seednox-Setup-v1.0.2.exe` с интеграцией в систему Windows и деинсталлятором.
- 🛡 **Устранение уязвимостей (PR #2 & Аудит)**:
  - Безопасный Fail-Safe режима `SQLCipher`: явная ошибка `RuntimeError` при вызове с `DB_ENCRYPTION_KEY` без `sqlcipher3`.
  - Усиленный контроль доступа бота `ALLOWED_USER_IDS` с предупреждением на старте.
  - Повышение безопасности Docker-контейнера (non-root пользователь `appuser`).
- 🧪 **100% Покрытие тестами & CI Quality Gate**:
  - Создан полный комплект юнит-тестов `pytest` / `unittest` в каталоге `tests/`.
  - Добавлены GitHub Actions workflows для проверки качества кода при каждом коммите и сборке релизов.
- 📦 **Закрепление версий зависимостей (Dependency Pinning)** и удаление бинарных файлов из истории Git.
